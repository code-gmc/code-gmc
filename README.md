# Welcome to GMC Digital Tools ⛪✨

We build tools and WordPress plugins designed to help local churches and non-profits streamline operations so they can focus on ministry and community outreach.

### Our Mission & Story
What started as a set of internal tools for our local church is growing into a free, open-source suite of resources. We believe ministry software should be simple, effective, and accessible to churches of all sizes.

### Featured Projects (Coming Soon)
- ⚙️ **GMC Operations** — Core platform for church management.
- 📱 **Church SMS Connect** — Twilio-powered "All-Call" broadcasting.
- 📅 **Ministry Calendar** — Custom events calendar plugin.
- 🎈 **VBS Manager** — Registration and event management for Vacation Bible School.

---
*All tools are currently in active private development and will be released free to the public!*
