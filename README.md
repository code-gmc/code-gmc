# Welcome to GMC Digital Tools ⛪✨

We have built tools and WordPress plugins designed to help local churches and non-profits streamline operations so they can focus on ministry and community outreach. We use this custom plugin to semi-automate and save time creating Bulletins, the Sunday Service PowerPoints, Church records and a custom SMS - ALL-CALL church text/email blast. 

### Our Mission & Story
What started as a set of internal tools for our local Gillespie Methodist Church is growing into a free, open-source suite of resources. We believe ministry software should be simple, effective, and accessible to churches of all sizes.

### Featured Projects (Open sourced. - Coming Soon)
- ⚙️ **GMC Operations** — Core platform for church management.
- 📱 **Church SMS Connect** — Twilio-powered "All-Call" broadcasting.
- 📅 **Ministry Calendar** — Custom events calendar plugin.
- 🎈 **VBS Manager** — Registration and event management for Vacation Bible School.
- 🎥 **Sunday Service Workflow** - PowerPoint, Live Stream, Sermons and more.
